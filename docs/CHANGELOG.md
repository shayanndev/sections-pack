# Changelog

All notable changes to Sectionary are documented here.

## 1.0.0 — 2026-10-02

### Added

- 30 standalone React and Tailwind CSS landing-page sections.
- Interactive Next.js preview browser with category filtering and copy-code controls.
- Desktop and mobile preview modes with scrollable mobile frames.
- Indigo, Emerald, Rose, and Mono theme presets.
- Light and dark color modes backed by centralized semantic design tokens.
- Five complete page examples: SaaS, Agency, Portfolio, Mobile App, and Product Launch.
- TypeScript prop interfaces and default content for every section.
- Accessibility foundations including semantic markup, focus-visible styles, labeled inputs, and native FAQ disclosure controls.
- Product documentation, section catalog, restricted commercial license, and AI customization guide.

### Verified

- Responsive behavior at 360px, 768px, and 1280px design breakpoints.
- Production build with Next.js 16.
- ESLint with Next.js Core Web Vitals and TypeScript rules.
